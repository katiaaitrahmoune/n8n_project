# n8n_project

Workflow **n8n** permettant de transférer des données entre le code embarqué d'un **ESP32** et un environnement **Node.js**, en utilisant **Google Drive** comme outil d’échange des données.

## Fonctionnalités

- Transfert automatique des données depuis l’ESP32 vers Node.js.  
- Utilisation de **Google Drive** pour stocker et partager les fichiers.  
- Workflow entièrement automatisé avec **n8n**.  
- Compatible avec les projets IoT et les environnements serveur Node.js.

---

## Technologies utilisées

- **ESP32** (hardware device)  
- **Node.js server**  
- **n8n**  
- **Google Drive**
